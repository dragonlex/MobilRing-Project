# MobilRing — проект целиком

Бюро находок для города: человек публикует объявление о пропаже или находке с телефона,
серверный скрипт сам находит совпадения и присылает их обоим участникам. Ничего общего
в базе не видно — показывается только результат сравнения.

Проект собран из двух репозиториев, которые лежат здесь как подмодули.

## Репозитории

| Репозиторий | Что внутри | Стек |
|---|---|---|
| [MobilRing](https://github.com/dragonlex/MobilRing) | Android-приложение: публикация, лента, уведомления, профиль, звонок автору | Kotlin, Jetpack Compose, Firebase |
| [MobilRing-Server2](https://github.com/dragonlex/MobilRing-Server2) | поиск совпадений: эвристика + локальная языковая модель | Python, Firebase RTDB, KoboldCpp |

## Как связаны части

```
  телефон A                  Firebase RTDB                телефон B
┌───────────┐              ┌────────────────┐            ┌───────────┐
│  пропажа  │──публикация─▶│  lost          │            │           │
└───────────┘              │  found         │◀─публикация│  находка  │
                           │  users         │            └───────────┘
                           │  matches       │
                           └───────┬────────┘
                                   │ читает/пишет
                           ┌───────▼────────┐
                           │  matcher.py    │  эвристика → LLM → пара
                           │  + KoboldCpp   │
                           └────────────────┘
```

1. Приложение пишет объявление в `lost` или `found` и контакты автора в `users/{uid}`.
2. `matcher.py` раз в минуту читает оба узла, оценивает пары и пишет подтверждённые в `matches`.
3. Приложение читает `matches` и показывает карточку только тем, чья заявка в паре участвует.

Схема полей и подробности — в README каждого репозитория.

## Быстрый старт

```powershell
# 1. Клонировать проект вместе с подмодулями
git clone --recurse-submodules https://github.com/dragonlex/MobilRing-Project.git
cd MobilRing-Project

# 2. Приложение
cd AndroidApp
$env:JAVA_HOME = "C:\Program Files\Android\Android Studio\jbr"
.\gradlew.bat assembleDebug
adb install -r app\build\outputs\apk\debug\app-debug.apk

# 3. Сервер совпадений
cd ..\Server2
.\start-kobold.ps1     # отдельное окно, локальная модель
.\start-matcher.ps1    # поиск в цикле
```

Если подмодули не подтянулись:

```powershell
git submodule update --init --recursive
```

## Состояние

- Приложение: рабочая версия 1.0, проверено на Android 10, 14, 16 и на эмуляторе Android 14.
- Матчер: эвристика + Qwen2.5-7B-Instruct через KoboldCpp; есть режимы `--once`, `--dry-run`,
  `--no-llm`.
- Совпадения проверены на живых объявлениях: «Плюшевый мишка» и «Рюкзак синий» находит
  с уверенностью модели 0.95, ложные пары вида «ключи от машины ↔ ключи от замка» отклоняет.
